# 中国古代城镇地理信息数据库交互图

这是一个单文件 HTML 交互地图，用于展示中国古代城镇核心种子库的空间分布、类型差异和若干历史文化标识。页面以中国古代城镇为主体，将城镇点位、类型图例、卫星底图、山川水系参考、国家历史文化名城星标和以西安为中心的八卦覆盖示意整合在同一个可点击地图中。

## 文件

- `中国古代城镇地图.html`：主页面，可直接用浏览器打开。
- `index (1).html`：同步到 Downloads 目录的副本，内容与主页面保持一致。

## 功能

- 展示 155 处中国古代核心城镇点位。
- 按类型区分都城/全国中心、区域城市、古镇/关隘/驿站、考古遗址/湮灭城址。
- 用红色小星标标识国家历史文化名城。
- 使用内嵌卫星影像瓦片作为底图，不依赖在线地图服务。
- 叠加黄河、长江、珠江及若干山脉作为地理参照。
- 以西安/唐长安为中心绘制八卦覆盖示意。
- 点击任一城镇点，可查看行政位置、功能类型、时代、规模、距离西安参照点、现状与来源说明。

## 视觉标识

- 红色三角形：都城/全国中心。
- 黄色方块：区域城市。
- 蓝色圆点：古镇、关隘、驿站。
- 紫色圆点：考古遗址、湮灭城址。
- 红色小星标：国家历史文化名城。
- 红色八卦线框：以西安为中心的空间示意覆盖。

## 数据口径

页面使用研究报告中的核心种子库数据，并将其转换为浏览器可渲染的 JSON 点位。坐标采用 WGS84 风格工作坐标。部分点位属于推断坐标或待源文件进一步替换的工作坐标，页面说明中以相关文字提示。

国家历史文化名城标识来自用户指定的历史文化名城资料整理，并已写入各城镇记录的 `historicalCulture` 字段。

## 维护说明

主要可调整位置在 `中国古代城镇地图.html` 的 `<script>` 中：

- `data`：城镇点位和属性数据。
- `imageryTiles`：内嵌卫星底图瓦片。
- `lonMin`、`lonMax`、`latMin`、`latMax`：地图显示范围。
- `drawBagua()`：八卦覆盖示意的绘制逻辑。
- `drawPoints()`：城镇标记和历史文化名城星标绘制逻辑。

修改后建议至少检查：

```bash
node -e "const fs=require('fs'); const s=fs.readFileSync('中国古代城镇地图.html','utf8'); new Function(s.match(/<script>([\\s\\S]*?)<\\/script>/)[1]); console.log('HTML script OK')"
```

## 注意事项

本页面适合用于研究展示、演示汇报和空间关系初步观察。八卦覆盖属于可视化解释层，不代表所有城镇营建均与八卦制度存在直接历史关系；具体个案仍需结合文献、考古和地方志材料判断。
